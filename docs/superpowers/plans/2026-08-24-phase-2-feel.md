# Phase 2 — Feel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Phase 1's flat squares with the thing that makes this game worth choosing — a glossy interpolated ribbon with glow, afterglow trails, particle bursts, shake, and flash, holding 60fps.

**Architecture:** The `Canvas` grows from one buffer to three (base, half-res glow, persistent trail) composited at quantize time. A per-segment SDF rasterizer draws the body as a continuous capsule chain. A `Fx` system owns particles, shake, and flash. `Theme` becomes a data record so Phase 4 only adds table entries.

**Tech Stack:** Rust 2021, ratatui-core 0.1.2, no new dependencies.

**Spec:** `docs/superpowers/specs/2026-08-23-terminal-snake-design.md`

## Global Constraints

- **The SDF must rasterize per segment, over that segment's own bounding box.** Never the whole polyline bbox × all segments: that is `O(length × arena_pixels)` — ~22 ms/frame at length 250 — and is the one finding the feasibility review called blocking.
- `r = 0.40 · scale`, `falloff = 0.5 + 0.15 · scale`. A fixed falloff at scale 3 makes the body entirely falloff with no solid core.
- Distance uses a `pixel_aspect: f32` multiplier so a non-square font does not distort the ribbon.
- **The glow buffer needs a blur pass.** Additive brightness with no spatial spread is not bloom. Half resolution, separable 5-tap Gaussian, two passes, bilinear upsample-add.
- **Trail decay is time-based:** `trail *= exp(-dt / tau)`. A per-frame constant doubles the afterglow at 30fps and erases it at 144Hz. Same for shake decay and highlight phase.
- Compositing stays in linear light; the quantizer sRGB-encodes and 5-bit snaps as it already does.
- Screen shake offsets the *sample* origin, so the canvas needs edge clamping.
- Death particles are a **fixed ~400**, not scaled by body length.
- `render/*` still touches no `std::io`, crossterm, filesystem, clock, or entropy. `dt` in, injected RNG.

```rust
use crate::render::color::{rgb_hex, Rgb};

#[derive(Clone, Copy, Debug)]
pub struct Theme {
    pub bg: Rgb,
    pub border: Rgb,
    pub body_head: Rgb,
    pub body_tail: Rgb,
    pub food: Rgb,
    pub glow_tint: Rgb,
    pub highlight: Rgb,
    /// Afterglow e-fold time in seconds.
    pub trail_tau: f32,
    pub glow_gain: f32,
}

impl Theme {
    pub fn default_theme() -> Theme {
        Theme {
            bg: rgb_hex(0x0b0f14),
            border: rgb_hex(0x1e2a38),
            body_head: rgb_hex(0x8affc1),
            body_tail: rgb_hex(0x0e6b3d),
            food: rgb_hex(0xff4d5a),
            glow_tint: rgb_hex(0x39ffa0),
            highlight: rgb_hex(0xe8fff4),
            trail_tau: 0.22,
            glow_gain: 0.9,
        }
    }

    pub fn body_at(&self, t: f32) -> Rgb {
        let t = t.clamp(0.0, 1.0);
        let mut out = [0.0; 3];
        for k in 0..3 {
            out[k] = self.body_head[k] * (1.0 - t) + self.body_tail[k] * t;
        }
        out
    }
}
```

```rust
pub fn decay_trail(&mut self, dt: f32, tau: f32) {
    let k = (-dt / tau.max(1e-4)).exp();
    self.trail.iter_mut().for_each(|p| { for c in p.iter_mut() { *c *= k; } });
}

pub fn add_glow(&mut self, x: f32, y: f32, c: Rgb) {
    let gx = (x * 0.5).round() as i32;
    let gy = (y * 0.5).round() as i32;
    if let Some(i) = self.gidx(gx, gy) {
        for k in 0..3 { self.glow[i][k] += c[k]; }
    }
}

/// Separable 5-tap Gaussian, two passes, at half resolution.
pub fn blur_glow(&mut self) {
    const K: [f32; 5] = [0.0625, 0.25, 0.375, 0.25, 0.0625];
    let (gw, gh) = (self.gw, self.gh);
    let mut tmp = vec![[0.0f32; 3]; gw * gh];
    for y in 0..gh {
        for x in 0..gw {
            let mut acc = [0.0f32; 3];
            for (t, &w) in K.iter().enumerate() {
                let sx = (x as i32 + t as i32 - 2).clamp(0, gw as i32 - 1) as usize;
                let s = self.glow[y * gw + sx];
                for k in 0..3 { acc[k] += s[k] * w; }
            }
            tmp[y * gw + x] = acc;
        }
    }
    for y in 0..gh {
        for x in 0..gw {
            let mut acc = [0.0f32; 3];
            for (t, &w) in K.iter().enumerate() {
                let sy = (y as i32 + t as i32 - 2).clamp(0, gh as i32 - 1) as usize;
                let s = tmp[sy * gw + x];
                for k in 0..3 { acc[k] += s[k] * w; }
            }
            self.glow[y * gw + x] = acc;
        }
    }
}
```

```rust
fn dist_to_segment(p: (f32, f32), a: (f32, f32), b: (f32, f32), aspect: f32) -> f32 {
    let (px, py) = ((p.0 - a.0) * aspect, p.1 - a.1);
    let (bx, by) = ((b.0 - a.0) * aspect, b.1 - a.1);
    let len2 = bx * bx + by * by;
    let t = if len2 <= 1e-9 { 0.0 } else { ((px * bx + py * by) / len2).clamp(0.0, 1.0) };
    let (dx, dy) = (px - bx * t, py - by * t);
    (dx * dx + dy * dy).sqrt()
}

pub fn stroke_segment(c: &mut Canvas, a: (f32, f32), b: (f32, f32), color: Rgb, s: &Stroke) {
    let reach = s.radius + s.falloff;
    // Only this segment's own neighbourhood is visited: cost is O(scale^2) per
    // segment, never O(arena).
    let x0 = (a.0.min(b.0) - reach).floor() as i32;
    let x1 = (a.0.max(b.0) + reach).ceil() as i32;
    let y0 = (a.1.min(b.1) - reach).floor() as i32;
    let y1 = (a.1.max(b.1) + reach).ceil() as i32;

    for y in y0..=y1 {
        for x in x0..=x1 {
            let d = dist_to_segment((x as f32, y as f32), a, b, s.pixel_aspect);
            let cov = 1.0 - ((d - s.radius) / s.falloff).clamp(0.0, 1.0);
            if cov > 0.0 { c.blend(x, y, color, cov); }
        }
    }
}
```

The acceptance criterion from spec §4.6: logic + canvas + quantize under **8 ms at scale 4 with 400 live particles**. Gated to release builds, because `opt-level = 1` dev timings would be meaningless and would fail spuriously.

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use std::time::Instant;

    #[test]
    #[cfg_attr(debug_assertions, ignore = "timing is only meaningful in release; run cargo test --release")]
    fn a_worst_case_frame_fits_the_budget() {
        let l = Layout::compute(120, 40, 4).unwrap();
        assert_eq!(l.scale, 4);
        let theme = Theme::default_theme();
        let mut c = Canvas::new(l.canvas_w, l.canvas_h);
        let mut fx = Fx::new(1);
        let mut g = Game::new(Mode::Classic, 1);
        let mut q = DirQueue::new(Direction::Right);
        g.start();
        // A long snake and a full death burst at once.
        for _ in 0..60 { g.grow_for_bench(); }
        fx.emit_death(&[(10.0, 10.0)], theme.body_head);
        assert_eq!(fx.live(), DEATH_PARTICLES);

        let mut buf = Buffer::empty(Rect::new(0, 0, 120, 40));
        let frames = 120;
        let start = Instant::now();
        for _ in 0..frames {
            g.advance(0.016, &mut q);
            fx.update(0.016);
            draw_arena(&mut c, &g, &l, &theme, &mut fx, 0.016);
            c.quantize_into(&mut buf, (l.origin_col, l.origin_row), ColorTier::Full, fx.shake_offset());
        }
        let per_frame = start.elapsed().as_secs_f64() * 1000.0 / frames as f64;
        assert!(per_frame < 8.0, "{per_frame:.2} ms per frame exceeds the 8 ms budget");
    }
}
```
